## Chromium 개발 환경 구축

### depot_tools 설치

```bash
git clone https://chromium.googlesource.com/chromium/tools/depot_tools.git
```

### Chromium 소스 다운로드

```bash
fetch --nohooks --no-history chromium
```

### 빌드 의존성 설치

```bash
./build/install-build-deps.sh
```

### Hook 실행

```bash
gclient runhooks
```

### Chromium 빌드 시도 

```bash
autoninja -C out/Default chrome
```
